# 🎓 College Event Registration Application

## ✨ Project Overview

This is a **College Event Registration Application** created using Figma. The application helps students view college events, check event details, and register for different college activities easily.

## 🎯 Objective

The main objective of this application is to make the college event registration process simple, easy, and convenient for students.
